# LibraSpace — онлайн-библиотека

Современная онлайн-библиотека с каталогом, выдачей книг, очередью, личным кабинетом читателя и админ-CRM.

## Стек

- **Next.js 16** (App Router) + TypeScript
- **PostgreSQL** + **Prisma**
- **Auth.js (NextAuth v5)** — клиенты и админ
- **Tailwind CSS 4** + **Framer Motion**
- **Docker Compose** для базы (и опционально всего стека)

## Возможности

### Для читателей
- Регистрация и вход
- Каталог со поиском, фильтрами и пагинацией (100+ книг)
- Выдача книги с лимитами и сроками
- Продление, возврат, расчёт штрафов
- Очередь / бронь, если экземпляров нет
- Личный кабинет: текущие выдачи, брони, история
- Отзывы после возврата книги

### Для администратора (CRM)
- Дашборд: статистика, топ книг, лента событий
- Управление фондом книг (CRUD)
- Карточки читателей с полной историей
- Все выдачи, фильтры, принудительный возврат
- Блокировка пользователей, заметки
- Настройки библиотеки (сроки, лимиты, штрафы)
- Журнал активности

## Быстрый старт

### 1. Зависимости

```bash
npm install
```

### 2. База данных (Docker)

```bash
npm run db:up
```

Нужен установленный Docker. Поднимется PostgreSQL на порту `5433` (чтобы не конфликтовать с локальным Postgres).

### 3. Миграции и seed

```bash
npm run db:setup
```

Создаст таблицы и заполнит:
- 100+ книг по 8 жанрам
- админа и демо-читателей
- примеры выдач и отзывов

### 4. Запуск

```bash
npm run dev
```

Откройте [http://localhost:3000](http://localhost:3000)

## Полный Docker (приложение + БД)

```bash
docker compose up --build
```

Приложение будет на порту `3000`, БД — внутри сети compose.

## Переменные окружения

Скопируйте `.env.example` → `.env` (уже есть для локальной разработки):

```
DATABASE_URL=postgresql://libraspace:libraspace@localhost:5433/libraspace?schema=public
AUTH_SECRET=длинный-секретный-ключ
AUTH_URL=http://localhost:3000
```
